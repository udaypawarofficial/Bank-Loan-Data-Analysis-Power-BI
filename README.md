
# Bank Loan Data Analysis & Dashboard Development

## Project Overview
Developed an interactive Power BI dashboard to analyze bank loan applications, funding performance, borrower demographics, and loan repayment trends.

## Tools & Technologies
- Power BI
- SQL
- Excel
- DAX
- Power Query

## Dashboards
### 1. Executive Summary
Analyzes total loan applications, funded amounts, amounts received, average interest rates, and debt-to-income ratios.

### 2. Trends & Overview
Explores monthly lending trends, regional distribution, loan terms, employment length, loan purposes, and home ownership.

### 3. Detailed Insights
Provides detailed loan-level information to support portfolio analysis and decision-making.

## Project Files
- `assets/` — Dashboard screenshots
- `data/` — Loan dataset
- `powerBI/` — Power BI report and dashboard PDF

## Key Outcomes
- Evaluated lending performance using KPIs.
- Analyzed borrower characteristics and loan distributions.
- Developed interactive dashboards for data-driven decision-making.
